# π0.5 双卡全参数训练 Smoke Test

2026-10-26（Asia/Shanghai）｜分支：`feature/pi05-flow-only-full`｜基线：`30e02369`

本页保留最初 smoke 的条件与结论；后续配置、工程复盘和正式启动命令见[总览](README.md)。

## 目标与结论

验证 RLinf PyTorch 能否在两张 48GB GPU 上，使用真实 FoldBox 数据完成 π0.5 全参数 SFT 的前向、反向传播和 optimizer step。

**结果：通过。** 两个 actor rank 分别使用 GPU 0/1，完成全部 5 个训练步骤；日志未发现 OOM、NaN/Inf 或异常堆栈。本次仅验证运行可行性，不评价收敛或机器人任务成功率。

## 实验设置

| 项目 | 设置 |
|---|---|
| 硬件 | 2 × NVIDIA RTX PRO 5000 Blackwell，每卡 48,935 MiB |
| 软件 | PyTorch `2.11.0+cu130`；RLinf FSDP1 |
| 初始权重 | 官方 JAX `pi05_base` 经 RLinf `jax_to_openpi` 转换 |
| 参数范围 | 3,353,433,872 个参数，CPU 模型加载检查确认全部可训练；LoRA 关闭 |
| 目标 | Flow Matching Loss；RTC、RLT 和辅助语义目标关闭 |
| 分片与精度 | `full_shard`，`use_orig_params=true`；FP32 参数存储与更新，BF16 混合精度计算、FP32 梯度归约 |
| 显存配置 | 梯度检查点开启，`use_reentrant=false`，`limit_all_gathers=true`；CPU offload 关闭 |
| Batch 与步数 | 每卡 micro batch 1，全局 batch 2；5 个 optimizer steps |
| 学习率 | 恒定 `1e-5`，warmup 0；梯度裁剪阈值 1.0 |
| 其他 | `torch_compile=false`；验证和 checkpoint 保存关闭；`JAX_PLATFORMS=cpu` 仅限制数据处理中的 JAX |

数据集为 `/home/deng/Documents/dataset/20260805_FoldBox_SpiritAI_Moz1WB_14Annotations/`，共 890 条轨迹、1,435,931 帧。保留原有 prompt 分布：overall + subtask 单 prompt，以及约 20% 帧的 overall-only 增广。

最小适配使用 `cam_high`、`cam_left_wrist`、`cam_right_wrist` 三路图像，缩放至 224×224；拼接 25 维 Cartesian state/action，底盘 action target 置零，使用本数据集已有的 quantile norm stats，补齐至模型的 32 维。Action Horizon 为 50，prompt token 上限为 200，`discrete_state_input=false`。本次未要求与旧推理流程完全一致。

训练循环合计约 7.30 秒，后四步平均约 1.36 秒/步，均不含环境、数据和模型初始化耗时。Loss 和梯度均有限；不同 batch 的五步 loss 波动不构成收敛证据。

预检查确认全部输出张量与按 RLinf 转换规则重建的 JAX 权重一致，并通过真实 batch 读取、FP32 模型加载及全部参数可训练检查。临时数据适配的两个单元测试通过，Ruff 和 `git diff --check` 通过。
